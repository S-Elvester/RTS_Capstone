RTS Capstone Project

This portfolio presents the application of an embedded fault-monitoring system designed for power infrastructure. It includes the system architecture, task design, hazard analysis, source code, timing evidence, and test results.

Project Overview

Explore how this real-time application detects, classifies, indicates, and records simulated power-grid fault events.

The full overview explains the interrupt-driven fault input, four prioritized FreeRTOS tasks, system data flow, ISR communication methods, and idle-versus-loaded testing.

Primary objective: Detect and report simulated power-system faults while preserving the timing requirements of the system's critical real-time tasks.

Task Table and WCET Evidence

The task table identifies each real-time task, its role, execution period, deadline, priority, processor core, and measured worst-case execution time.

These measurements provide evidence that the scheduling design can be evaluated using observed execution times rather than assumed values.

Hazard Analysis

The hazard analysis identifies possible system failures, their effects, the methods used to reduce risk, and the related safety-standard clauses.

A major concern is missed or delayed fault recognition. The application reduces this risk using interrupt-based detection, high-priority monitoring, preemptive scheduling, and real-time event logging.
