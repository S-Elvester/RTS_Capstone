Final Reflection

A reflection on the challenges, lessons, and personal growth experienced while completing the RTS Capstone Project.

Project What I Would Do Differently Harder Than Expected Most Valuable Lesson Original Writing

Project

This system is designed to ensure that a power grid can swiftly detect a fault and log the events for proper documentation.

Main purpose: Provide timely fault recognition and maintain a clear record of detected events for monitoring and analysis.

What I Would Do Differently

If I approached this project again, I would spend more time analyzing each line of every application so I could better understand good coding practices.

At the beginning, I felt substantial pressure to complete assignments quickly. That pressure caused me to move too recklessly through some of the applications instead of slowing down and studying how each part worked.

This reduced an important opportunity to strengthen one of my weaker areas, which is coding.

What Was Harder Than Expected?

Interacting with the web server was much more intimidating than I expected.

I had to determine how to safely locate and manage my IP information while attempting to make the web server functional.

This became even more daunting because I was working on UCF property and was unsure how to complete the process safely without making a dangerous or improper networking change.

The Most Valuable Thing I Learned

The most valuable lesson was learning how to approach intimidating concepts in computer science and coding.

I can confidently approach mathematics and other knowledge-based topics, but I often become hesitant when faced with complex code.

This class forced me to confront that challenge. Going forward, I will approach coding projects with more confidence while still working carefully and safely.

Interacting with the Web Server. This ended up being an extremely intimidating feature to try and work with. Learning how to approach daunting concepts in the realm of computer science and the world of coding. I can march bravely into any mathematics or knowledge-based topic, but I tend to cower in the presence of complex code. This class forced me to have to brave that dragon. Going forward I will go unabashed into coding projects, safely of course.
